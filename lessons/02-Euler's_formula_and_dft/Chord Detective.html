Use the frequency spectrum to unmask a hidden chord

Pure Tone: each note is one sine wave. Instrument: each note adds decaying harmonics, like a plucked string.

Big idea — one complicated waveform can contain several frequencies at once. The frequency spectrum is how we uncover them.
